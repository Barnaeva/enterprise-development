# BeautySalon

Лабораторная работа № 3. Вариант 4. «Салон красоты»

Реализовать серверное приложение, которое должно осуществлять базовые CRUD-операции с сущностями,
предоставлять резултаты аналитических запросов.

Хранение данных осуществляется в памяти в виде коллекций.

## Структура проекта

### BeautySalon.Domain

Основной проект с классами предметной области.

#### Entities

- `Person` — базовый класс для клиента и мастера.
- `Client` — клиент салона.
- `Master` — мастер, оказывающий услуги.
- `Services` — услуга салона и её стоимость.
- `Appointment` — запись клиента на услугу к мастеру.

#### Data

- `DataSeeder` — тестовые данные проекта.

Содержит:
- 10 мастеров;
- 10 клиентов;
- 10 услуг;
- 14 записей.

---

### BeautySalon.Tests

Проект с unit-тестами.

#### BeautySalonTests

Класс с тестами с LINQ-запросами и проверками результатов.

#### Тесты

##### GetMastersWithExperienceAtLeastFiveYears

Находит всех мастеров, стаж работы которых не менее 5 лет.

##### GetFreeSlotsForSelectedMaster

Находит свободные окошки выбранного мастера — промежутки времени между двумя соседними записями на услугу.

##### GetTopFivePopularServices

Находит топ-5 наиболее популярных услуг.

Используется группировка по услуге и подсчёт количества записей.

##### GetNumberOfRepeatClientAppointmentsForLastMonth

Определяет количество повторных записей клиентов за последний месяц.

##### GetClientsRegisteredWithSeveralMasters

Находит клиентов, записанных к нескольким разным мастерам, упорядоченных по дате рождения.
